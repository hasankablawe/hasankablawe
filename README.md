# 👋 Hello, I'm Hasan Kablawy

I'm an **AI & Computer Vision Engineer** based in **Egypt**, specializing in real-time detection, edge deployment, and end-to-end system architecture. I focus on bridging the gap between deep learning research and production, optimizing complex vision pipelines to run reliably on constrained hardware and cloud infrastructure.

## 🌟 What I Do

- **End-to-End Edge Deployment:** I transition models from PyTorch into high-speed production environments. I specialize in INT8/FP16 quantization and compiling models using **TensorRT, ONNX Runtime, and NCNN** to maximize FPS and minimize memory footprints on constrained edge devices like the Raspberry Pi 5 and Jetson series.
- **Real-Time Vision & Tracking Pipelines:** I build high-throughput solutions for multi-object tracking (MOT), instance segmentation, and zero-shot classification. My work utilizes state-of-the-art architectures like **RT-DETR, YOLOv8, and SAM 2** to solve complex challenges, ranging from industrial OCR barcode inspection to heavy-occlusion sports analytics.
- **Production Inference Architecture:** I design the backend infrastructure required to serve deep learning models reliably. I build robust **FastAPI** microservices, containerize pipelines with **Docker**, and interface directly with physical network switches to extract raw RTSP streams from NVR/DVR systems, bypassing proprietary vendor lock-in.
- **Advanced Spatial & Temporal Analytics:** I engineer complex analytical solutions beyond standard bounding boxes. This includes developing unsupervised anomaly detection using Convolutional Autoencoders and LSTMs for live CCTV feeds, and building Visual SLAM navigation stacks for autonomous indoor mapping.
